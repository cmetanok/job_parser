# Job Parser — дашборд для анализа вакансий

Интерактивный дашборд для анализа вакансий с российских job-платформ: **Habr Career** и **Trudvsem** («Работа России»).

Проект собирает данные через публичные API, нормализует их, фильтрует и показывает аналитику в удобном веб-интерфейсе на Streamlit.

🔗 **Живая демо-версия:** 

---

## Возможности

- **Сбор вакансий** с двух источников: Habr Career и портал «Работа России» (Trudvsem)
- **Фильтрация** по городу, уровню/опыту, зарплате, удалённой работе
- **Сортировка** по дате публикации, по зарплате (убывание/возрастание), по названию
- **Пагинация** для удобного просмотра большого количества вакансий
- **Аналитика**: топ-15 навыков, топ-15 городов, распределение зарплат
- **Метрики**: общее количество вакансий, компаний, городов, средняя зарплата
- **Кэширование** результатов парсинга на 1 час для ускорения работы

## Установка и локальный запуск

### 1. Клонируй репозиторий

```bash
git clone https://github.com/cmetanok/job_parser.git
cd job_parser
```

### 2. Создай виртуальное окружение

Windows:
```powershell
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:
```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Установи зависимости

```bash
pip install -r requirements.txt
```

### 4. Запусти приложение

```bash
streamlit run app.py
```

Открой браузер по адресу `http://localhost:8501`.

## Как это работает

1. **Пользователь** вводит ключевое слово (например, `Python`), выбирает источники и количество страниц для парсинга.
2. **Парсеры** обращаются к публичным API Habr Career и Trudvsem, собирают вакансии и нормализуют их в единый формат.
3. **Данные** сохраняются в `st.session_state` и кэшируются на 1 час через `@st.cache_data`.
4. **Фильтры** применяются к уже собранным данным без повторного парсинга.
5. **Аналитика** строится на отфильтрованной выборке: графики, метрики, распределения.

## Источники данных

### Habr Career

- **API:** `https://career.habr.com/api/frontend/vacancies`
- **Авторизация:** не требуется
- **Формат:** JSON, пагинация по 25 вакансий на страницу
- **Признак удалёнки:** проверяется через структурированное поле API и HTML-страницу вакансии

### Trudvsem («Работа России»)

- **API:** `https://opendata.trudvsem.ru/api/v1/vacancies`
- **Авторизация:** не требуется
- **Формат:** JSON, пагинация через `offset`/`limit`
- **Признак удалёнки:** поле `employment_type` (например, «Дистанционная (удалённая) работа»)

## Нюансы и ограничения

### hh.ru не поддерживается

С апреля 2026 года HeadHunter закрыл публичный API для неавторизованных запросов: метод `GET /vacancies` возвращает `403 Forbidden`. Ключи выдают только подтверждённым работодателям после модерации. Легального способа автоматически собирать вакансии с hh.ru без токена работодателя не осталось.

### Средняя зарплата

Метрика рассчитывается **только по вакансиям с указанной зарплатой**. В сноске под метриками показывается, по скольким вакансиям из общего числа рассчитано среднее.

### Удалённая работа

Не все вакансии содержат явный признак удалёнки:

- В Habr Career признак может быть в структурированном поле `remote` или в HTML-странице вакансии
- В Trudvsem признак лежит в `employment_type`, но не во всех вакансиях

Фильтр находит только те вакансии, где признак явно указан.

### Лимиты API

Habr Career и Trudvsem могут ограничивать частоту запросов. При большом количестве страниц парсинг может занять время. Кэширование на 1 час снижает нагрузку на API.

### Засыпание на Streamlit Cloud

Бесплатные приложения на Streamlit Cloud засыпают после нескольких дней неактивности. Первый заход после паузы занимает 30–60 секунд. Для поддержания активности можно использовать сервисы вроде `streamlit-wakeup` или GitHub Actions с периодическим пингом.
